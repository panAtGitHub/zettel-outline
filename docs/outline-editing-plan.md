# 大纲编辑实验计划

分支：experiment/outline-editing。现有样式一保持不变，新增交互先用于样式二。

## 实施顺序

1. 键盘导航：独立的键盘选中行；上下移动可见行；Enter 打开笔记并保留大纲焦点；左右展开、折叠、进入子行或返回父行。只在大纲自身获得焦点时处理快捷键。
2. 内存撤销框架：Ctrl+Z 撤销；Ctrl+Y / Ctrl+Shift+Z 重做；最多 100 次，重载清空，不持久化。成功操作整组入栈，新修改清空重做栈。外部文件变更时重新校验。
3. F2 行内改名：只修改标题，保留编号；Enter 确认，Esc 取消；占位行进入补建。通过 Obsidian 文件管理接口改名，支持撤销。
4. 排除规则：排除文件夹；可选的合法日期编号排除（默认关闭）。统一作用于索引、转换范围、编号占用；所有文件仍参与目标路径冲突检查。
5. Tab / Shift+Tab：降级至前一个同级条目之下／升级至父项同级；整棵子树一起重新编号；目标末级最大编号加一，不重排其他兄弟。预检、串行批量改名、失败恢复、整组撤销。不写持久化历史；进程崩溃恢复不在第一版保证范围内。
6. 批量转换命名规则：层级分隔符、标题分隔符、编号位置可组合转换。旧规则解析，新规则生成；预览改名清单、排除项、冲突；成功后切换设置并重建索引。文件改名与规则变更作为一次可撤销操作。

## 共同约束

- 导航选中和当前打开文件是两个状态；方向键不改文件、不自动打开。
- 选择、滚动、展开折叠不进入撤销历史。
- 新建和删除暂不纳入撤销；删除使用回收站。
- 输入框和中文输入法的按键不被大纲截获。
- 空缺中间层级保留编号、缩进和空标题。
- 每步单独验证；行为修改执行 npm test，插件修改执行 npm run build:obsidian。

## 当前进度

- 第一阶段已实现：上下可见行导航、左右展开折叠和父子导航、Enter 打开或补建、Home/End、独立选中高亮；自动测试通过。
- 第二、三阶段已实现：内存历史最多 100 次；Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z；F2 标题行内改名，Enter 确认、Esc 或离开输入框取消；空标题行 F2 进入补建窗口。
- 改名保留原始编号字符串（包括前导零），通过文件管理接口更新链接；撤销前检查规则、文件对象、路径和冲突。索引更新失败尝试恢复原路径。
- 新建、删除仍不进入历史；排除规则、层级移动、批量转换尚未实现。

- 已增加面板快捷键设置：按键录入、组合键、清除、恢复默认和重复绑定检测，立即作用于面板捕获与动作执行。

- 第四阶段已实现：排除文件夹（含子目录、精确路径边界）和有效 YYYY-MM-DD 日期编号（默认关闭）。索引全量与增量使用同一判断，规则变更标记索引过期；编号建议忽略排除文件，但创建冲突检查仍计入所有文件，禁止创建落入排除规则的新笔记。新增 2 项自动测试。

- 第五阶段已实现：默认 Tab 降级、Shift+Tab 升级（可自定义），整组文件改名、占位层级移动、目标最大编号加一、冲突预检、执行失败恢复、内存整组撤销重做。批量改名期间暂缓索引刷新；完成后定位到新编号，撤销定位到旧编号。尚不保证进程崩溃时恢复。

- 已加入样式二鼠标拖拽层级移动：行中央作为子项，下沿作为同级，底部落点移到顶层。复用整棵分支事务及撤销；拒绝循环及同父级空操作。保留数字排序，不支持拖拽插入到指定兄弟之前。

- 拖拽交互第二轮：参照 Workflowy、RemNote 官方说明，改为横向投射层级，加入渐进底色、缩进落点线、明确父级提示和 650ms 悬停展开。完整研究见 drag-interaction-research.md。旧的“底部 25% 同级”热区已移除。

- 已按用户确认升级为位置排序：编号继续决定顺序，拖动标题或编号超过 5px 开始拖动，点击仍打开；Esc 取消、拖动后的 click 被抑制。使用最近纵向插入边界及横向层级选择 before/after/inside。新增 Ctrl+Shift+上下同级分支移动及可自定义绑定。
- 位置移动在目标同级的现有编号槽位上重新分配；跨父级插入增加一个末尾槽位，不要求将编号全部重排为连续数字。受影响分支与后代一起改名；使用两阶段临时路径解决同名文件交换冲突，整组撤销及失败回滚。该临时路径不是持久化历史；不保证进程中断恢复。
- 第一版上下快捷键到同级边界即停止，不自动跨父级；跨父级可用拖拽或 Tab/Shift+Tab。拖动时插入线是主反馈，目标父项渐变为辅。

- 已加入结构历史：左右两列对比、差异着色、同步滚动及折叠、箭头浏览、独立 history.json 与预操作记录、恢复预检和整组可撤销恢复。详细范围及限制见 structure-history.md。

- 快捷键方案已落实，升降级/位置移动/创建统一到 TreeEdit 逻辑树规划器：升一级紧跟原父节点，来源和目标同级连续编号；新建同级紧随选中项；新建父节点支持包裹和空父级补建。创建操作可撤销（已有正文时阻止移除），自定义快捷键优先于新增默认。完整键表见 panel-shortcuts.md。
