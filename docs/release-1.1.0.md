# Zettel Outline 1.1.0

First public release of the recovered and extended Zettel Outline project.

- Numeric outline navigation with classic and list views.
- Parent/child/sibling creation, renaming, drag ordering, and keyboard editing.
- Configurable shortcuts, exclusions, and appearance.
- Persistent structure history with comparisons, undo/redo, and restore.
- MIT license and English/Chinese UI.

Install the three attached runtime files into .obsidian/plugins/zettel-outline. Preserve data.json and history.json when upgrading. Community availability depends on Obsidian review.
