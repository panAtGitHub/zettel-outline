# 面板快捷键与结构规则

快捷键仅在样式二的笔记树获得焦点时生效。名称输入框保留普通文字编辑行为，中文输入法组合期间不执行结构操作。

| 操作 | 默认快捷键 |
| --- | --- |
| 上下选择 | ↑ / ↓ |
| 折叠或父节点、展开或子节点 | ← / → |
| 第一行、最后一行 | Home / End |
| 打开当前笔记 | Enter |
| 改名 | Alt+Enter |
| 降一级、升一级 | Tab / Shift+Tab |
| 分支上移、下移 | Ctrl+Shift+↑ / ↓ |
| 新建同级 | Ctrl+Enter |
| 新建子级 | Ctrl+Shift+Enter |
| 新建父节点 | Ctrl+Alt+Enter |
| 全部展开、全部折叠 | Ctrl+Alt+↓ / ↑ |
| 删除当前文件 | Delete |
| 撤销 | Ctrl+Z |
| 重做 | Ctrl+Y / Ctrl+Shift+Z |
| 查看实际快捷键 | Ctrl+/ |
| 新建顶层、结构历史 | 默认留空，可在插件设置中绑定 |

所有绑定可在插件的面板快捷键分区修改；用户已有的自定义绑定优先于新增默认值，显式清除的绑定保持禁用。打开并聚焦面板的全局命令仍在 Obsidian 快捷键设置中配置。

## 编号规则

结构决定编号。结构操作先修改逻辑树，再计算整个受影响范围的文件改名清单，统一处理互换路径、冲突、失败恢复和内存撤销。

- 升一级：放到原父节点之后；原父级剩余子项从 1 连续编号，目标层同级从 1 连续编号；所有受影响后代的前缀同步更新。
- 降一级：成为前一个同级的末尾子项，来源层与目标层连续编号。
- 同级新建：默认紧跟选中条目插入；子级新建：默认追加为末尾子项。可在创建窗口选择本层合法插入位置，其余条目顺延。
- 新建父节点：若已有空父级，补建该父级文件；否则在当前位置包一层，选中条目及后代下移一级。
- 上下移动和拖拽：同样使用连续编号规则。只整理被直接编辑的同级列表，未被编辑的深层子列表保留自己的末级编号。
- 打开插件或重建索引不会自动重新编号。

例如原来为 xxx+1、zzzz+1-1、保留的子项+1-2、yyy+2；对 zzzz 升一级后为 xxx+1、保留的子项+1-1、zzzz+2、yyy+3。

## 创建和恢复

新建同级、子级、父级、顶层及补建均接入内存撤销和结构历史。撤销创建仅允许移除仍为空正文的原文件；文件已有正文时阻止撤销，避免误删。删除当前文件仍走回收站，子项保留，尚未作为可撤销的分支删除纳入。
